## 数据来源

- **library-import**：从本地 PDF 文献库批量导入（~90 篇 Lite 笔记）
- **paper-reader**：逐篇精读生成完整笔记（含公式、架构图、实验表格、批判性分析）
- **daily-papers**：每日自动抓取 HF Daily + arXiv，打分筛选后生成推荐日报
