## 🔥 一周方向小评

### 全双工 / 对话
本周最热的方向，三篇 🔥 全在这里。更重要的是三篇正好覆盖了不同的痛点：**ModeratorLM** 解决"多人场景下谁该说话"（模型能力），**DialogueSidon** 解决"高质量分轨训练数据从哪来"（数据瓶颈），**FastTurn** 解决"turn detection 怎么又快又准"（部署延迟）。三者串起来就是一条完整的全双工对话 pipeline——用 DialogueSidon 从 YouTube/podcast 挖数据 → 训练 ModeratorLM 做角色化决策 → 用 FastTurn 做前端低延迟触发。全双工从"范式期"走向"工程化"的信号越来越强。

### Speech LLM / S2S
PRIME-Speech 抓住了一个真实的工程矛盾：fine-tune backbone 加语音输出会降 S2T 能力，但 pipeline 接 TTS 又太慢。Frozen backbone + per-layer post-decoder 的折中方案比全量微调和简单 adapter 都优雅。FlexiSLM 提出动态帧率也是刚需——固定 50Hz 在静音段浪费惊人。但两篇都需要更完整的实验验证，PRIME 的音质天花板由 CosyVoice2 codec 决定，FlexiSLM 的 frame merging 准确性存疑。

### TTS / 语音合成
本周 TTS 不卷 zero-shot 质量了，转向**效率**和**可控性**两个维度。UnifiedGuidanceFM 干掉 CFG 实现 3x 加速是工程刚需；GeometricEmotionSteering 用 LID 量化了"SLM 阶段比 CFM 阶段更适合做情感注入"这个直觉。两篇互补：一篇管推理速度，一篇管可控性。HPRO 的层次化 reward optimization 也在做情感 TTS，但走的是 RLHF 路线而不是 steering。三篇撞车情感 TTS，说明这个子方向确实在升温。

跨日撞车提醒：**HPRO**（6-30，reward optimization）vs **GeometricEmotionSteering**（7-03，activation steering）——两种截然不同的情感控制范式，前者靠训练后优化，后者靠推理时干预。前者重但效果可能更稳，后者轻但可控上限有限。都在 CosyVoice2 上做的实验。

另一个撞车：**Enhanced-BEST-RQ**（RWTH）vs **BEST-RQ-2**（Toulouse）——两个组同一周改同一个 baseline。RWTH 走 PCA + 迭代更新，Toulouse 走 contextualize-then-predict。SSL pre-training 的微调空间还在被挤压。

### ASR
主流 ASR 的 low-hanging fruit 确实摘完了。CertifiedASR 是统计认证思路新颖但计算开销重；NPUsper 是纯系统工程工作但实用价值高。排除池里扎堆的小语种/临床 ASR（Bambara、Bantu、dysarthric、stuttered）说明这个方向的研究在分化。
