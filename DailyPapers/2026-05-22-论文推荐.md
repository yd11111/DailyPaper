## Speech LLM / 语音基座

### 1. StepAudio 2.5 Technical Report
- **链接**: [arXiv](https://arxiv.org/abs/2605.23463) | [PDF](https://arxiv.org/pdf/2605.23463)
- **来源**: 📄 arXiv 关键词检索
- 📒 **笔记**: [[StepAudio2.5]]

StepAudio 2.5 是 StepAudio 的大版本升级，从"拼装系统"走向"统一基座"。共享 backbone 通过 directional inference 实现 ASR/TTS/实时交互的任务特化，数据引擎和渐进式预训练也统一了。摘要声称 ASR/TTS 都达到了 specialized system 的水平，同时实时交互能力也在线。这是 Speech LLM 领域"统一 vs 专用"之争的又一个重要数据点。

**锐评**: 统一基座说了这么久，能三个方向都不拉垮才是真本事。但 "match specialized systems" 这个 claim 需要看具体数字——是在哪些 benchmark 上 match？跟 Whisper large-v3 / CosyVoice2 / Moshi 这些各领域最强的比了没有？另外 realtime specialization 的延迟数字摘要没给，这是全双工系统最核心的指标。🔥

## TTS / 语音合成

### 2. Natural Yet Challenging to Detect: Robust In-the-Wild TTS through EMA and Dual-Scoring Prompt Selection
- **作者**: Renhe Sun, Jiayi Zhou, Haolin He, Yueying Feng, Jian Liu
- **机构**: The Chinese University of Hong Kong, Zhejiang University
- **链接**: [arXiv](https://arxiv.org/abs/2605.23859) | [PDF](https://arxiv.org/pdf/2605.23859)
- **来源**: 📄 arXiv 关键词检索

- **核心方法**: 基于 [[F5-TTS]] 架构的 WildSpoof Challenge 参赛方案。输入 text + reference audio → [[F5-TTS]] + EMA fine-tuning → 合成语音。两个改进点：(1) EMA 在 SFT 阶段稳定训练、提升泛化；(2) Dual-Scoring Prompt Selection 用 LLM + Audio LLM 双打分过滤 reference audio 和 text prompt，提升 in-the-wild 场景的合成保真度。
- **对比方法/Baselines**: 基于 [[F5-TTS]]，评测指标包括 [[UTMOS]]、WER、DCF（检测代价函数）、[[DNSMOS]]。属于 challenge submission，主要与其他参赛方案对比。
- **借鉴意义**: EMA fine-tuning 这个技巧简单有效，做 TTS fine-tuning 的可以直接抄。Dual-scoring prompt selection 用 LLM+LALM 过滤参考音频的思路对 zero-shot TTS 的 prompt 工程有参考价值。
- **锐评**: 这是 challenge submission 不是独立方法论文，两个技巧（EMA + prompt 过滤）都不算 novel。但胜在工程实用——in-the-wild 数据质量参差不齐时，prompt selection 确实是低成本提升方案。不过摘要没给最终排名和具体指标，需要看全文确认效果。👀
- **🧪 锐评依据**：
  - `Claim: 两个技巧都不算 novel` | `Evidence: EMA 是标准训练技巧；prompt selection 在 zero-shot TTS 中已有先例（如 CosyVoice 的 prompt engineering）` | `Confidence: 高`

### 3. Frame-Aligned Fusion of Canary and WavLM for Non-Intrusive Intelligibility Prediction of Hearing-Aid-Processed Speech
- **作者**: Kazushi Nakazawa
- **机构**: 未明确（单作者）
- **链接**: [arXiv](https://arxiv.org/abs/2605.23619) | [PDF](https://arxiv.org/pdf/2605.23619)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2605.23619v1/x1.png)

- **核心方法**: 用 Canary（ASR encoder）和 [[WavLM]] 两个冻结 speech encoder 做非侵入式语音可懂度预测。核心问题是两种表示在哪一层融合最好——对比了 score averaging、pool-late fusion、cross-attention、frame-aligned fusion 等策略。输入为助听器处理后的语音 → 双 encoder 提取特征 → 融合 → 预测 intelligibility score。
- **对比方法/Baselines**: 对比 [[STOI]]、HASPI 等传统指标；方法上对比了 Canary 单模型、[[WavLM]] 单模型、以及多种融合策略。CPC3 challenge 框架。
- **借鉴意义**: 对做 TTS/ASR 的人价值不大。做语音质量评估（如 [[UTMOS]] / [[DNSMOS]] 类系统）的可以参考其 frozen encoder 融合策略。
- **锐评**: CPC3 challenge 的参赛方案，方向很窄（助听器语音可懂度）。单作者、无代码、无开源。融合策略的对比做得还算扎实（有 ablation），但这个任务的天花板本身就很低，对主流语音研究几乎没有影响。💤
- **🧪 锐评依据**：
  - `Claim: 方向很窄，对主流语音研究几乎没有影响` | `Evidence: 摘要明确限定为 "hearing-aid-processed speech" + "3rd Clarity Prediction Challenge"` | `Confidence: 高`
