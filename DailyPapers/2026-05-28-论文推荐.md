### 1. LoSATok: Low-dimensional Semantic-Acoustic Tokenizer for Cross-Domain Audio Understanding and Generation
- **作者**: Zhisheng Zhang
- **机构**: Shenzhen International Graduate School, Tsinghua University
- **链接**: [arXiv](https://arxiv.org/abs/2605.21636) | [PDF](https://arxiv.org/pdf/2605.21636)
- **来源**: 📄 arXiv 关键词检索

- **核心方法**: 解决"audio understanding 要高层语义、audio generation 又要声学细节"的统一 tokenizer 难题。在已有的 [[DashengTokenizer]] 之上提出 SemBo (Semantic Bottleneck)，引入 KL 散度做 [[FlowMatching]] DiT 友好的低维 latent，配合 PCA effective rank 分析降维。输入语音波形，输出统一离散 token，同时供下游 understanding（[[XARES]] / [[MiDashengLM]]）和 generation（[[TTS]]、[[TTA]]、[[TTM]]）使用。号称首个真正"低维 + 跨域"的统一 tokenizer。
- **对比方法/Baselines**: 对比 [[DashengTokenizer]]、[[CLAP]]；下游评测用 [[FSC]] / [[ESC]] / [[GTZAN]] / [[AudioCaps]] / [[WavCaps]] / [[FAD]] / [[SIM]] / [[UTMOS]]；生成端用 [[DiT]] 架构。
- **借鉴意义**: 对做 Audio Codec / Speech Tokenizer 的人是直接对照工作。"低维 latent + KL 正则 + DiT 友好"这条路径，本质上是把 [[FSQ]] / [[VQ-VAE]] 的离散化思路重做一遍。SemBo 这个 semantic bottleneck 设计是不是真比 [[FlexiCodec]] 的多码本更优，需要看具体码率-质量曲线。
- **锐评**: Tsinghua SIGS 出的 codec/tokenizer 工作历来扎实，但今天这篇 abstract 没给硬数字，章节也没专门的 SOTA 对比表，只看"Audio Understanding/Generation"两节标题判断不出究竟超过 baseline 多少。"统一 tokenizer 跨域 SOTA"的 claim 需要看完整文才能确认。值得精读 — 至少 SemBo + KL 这个设计点子有借鉴价值。🔥
- **🧪 锐评依据**:
  - `Claim: 是真正"低维+跨域"的统一 tokenizer` | `Evidence: 章节 'KL Divergence in LoSATok' + 'Impact of DiT Dimensions' + 'Audio Reconstruction'，明确把 DiT dim 和 KL 作为消融变量` | `Confidence: 中`
  - `Claim: abstract 没给硬数字` | `Evidence: abstract 末尾仅说 "demonstrating superior performance"，无具体 score/WER/FAD 数字` | `Confidence: 高`
  - `Claim: 设计思路对标 DashengTokenizer + FSQ 路线` | `Evidence: method_names 里 'DashengTokenizer', 'MiDashengLM', 'PCA', 'STFT' 全部点名` | `Confidence: 高`
- **关联笔记**: 对照 [[FlexiCodec]]（多码本设计）、[[FSQ]]（无码本量化）、[[ScalingSpeechTokenizers]]（tokenizer scaling law）。如果 LoSATok 真的解决 understanding-generation 鸿沟，会冲击当前 [[SoundStream]] / [[DAC]] 主流路线。

### 2. SwanBench-Speech: Comprehensive Benchmarking of Long-Form Speech Generation in Diverse Scenarios
- **作者**: Changhao Pan, Rui Yang, Zhou Zhao 等
- **机构**: 浙江大学 + 字节跳动
- **链接**: [arXiv](https://arxiv.org/abs/2605.21893) | [PDF](https://arxiv.org/pdf/2605.21893)
- **来源**: 📄 arXiv 关键词检索

- **核心方法**: 解决当前 TTS 评测基本只跑 10s 短句，对 minute-level / book-level long-form 生成无人系统评的问题。SwanBench-Speech 在多场景下采集 long-form 数据，定义专门的 long-form 指标（[[WER]] / [[MOS]] / [[PESQ]] / [[SQUIM]] / 韵律一致性 / [[SRCC]]）。提供完整自动评测 pipeline 并做了人类感知对齐测试。可直接评测 [[VibeVoice]] / [[CosyVoice3]] / [[MegaTTS3]] / [[SparkTTS]] / [[ZipVoice]] / [[ElevenLabs]] 等主流 NAR/[[LLM]]-based 长文本 TTS 系统。
- **对比方法/Baselines**: 评测对象覆盖 [[VibeVoice]]、[[CosyVoice3]]、[[MegaTTS3]]、[[SparkTTS]]、[[ZipVoice]]、[[ElevenLabs]]、[[OpenAI]] TTS、[[GPT-5]] audio。指标体系参考已有 TTS benchmark 但扩展到 long-context。
- **借鉴意义**: 对做 TTS 评测和 long-form TTS 训练的人是必备工具。当前 long-form TTS 真的有这么多系统已支持（VibeVoice 8 min、CosyVoice3 高音质 long-form）但缺评测标准，这就是该填的坑。字节出品质量有保障，pipeline 大概率会开源（章节有 "Data Refinement / Automatic Pipeline"）。
- **锐评**: 浙大 + 字节这套组合一向稳，long-form TTS 这个评测缺口确实是 2026 上半年的真问题（[[CosyVoice3]] / [[VibeVoice]] / [[VoxCPM]] 全都打 long-form 牌）。批判性看：abstract 没明说人类感知对齐的具体相关系数，"comprehensive" 这种字眼总让人警惕（每个 benchmark 论文都说自己 comprehensive）。需要确认场景覆盖是否真的涵盖播客/audiobook/对话/讲座等典型用例。🔥

### 3. Unlocking Fine-Grained and Within-Utterance Speaking Style Control in Prompt-Based Text-to-Speech Models
- **作者**: Jaehoon Kang
- **机构**: 成均馆大学（Sungkyunkwan University）
- **链接**: [arXiv](https://arxiv.org/abs/2605.21731) | [PDF](https://arxiv.org/pdf/2605.21731)
- **来源**: 📄 arXiv 关键词检索

- **核心方法**: 解决 prompt-based TTS（[[PromptTTS]] / [[InstructTTS]] / [[CosyVoice]]）的两个老毛病：(1) 给一个 style prompt 后全句应用同一风格，无法句内变化；(2) 风格之间无法平滑过渡。提出两套机制：① **Inter-Utterance Style Interpolation** — 在 style embedding 空间做 linear interpolation；② **Within-Utterance Style Transition** — 通过修改 KV cache 中的 early-token attention bias 来实现单句内风格变换。基于 LibriTTS 训练，与 [[NaturalSpeech]] / [[FastSpeech]] / [[CosyVoice]] / [[EmoSteer]] 对比 SIM / MOS / SPS（style preservation score）。
- **对比方法/Baselines**: 对照 [[PromptTTS]]、[[NaturalSpeech]]、[[InstructTTS]]、[[CosyVoice]]、[[FastSpeech]]、[[EmoSteer]]；其中 [[EmoSteer]] 是它的直接竞品（句内情感控制）。
- **借鉴意义**: 对做表达性 / 可控 TTS 的人价值很高。"early-token attention bias" 是个有意思的发现 — abstract 暗示作者通过 attention pattern analysis 找到了 prompt-based TTS 内部的局限。这个分析-改进路径可迁移到所有 prompt-based 模型。
- **锐评**: Within-utterance style 控制是当前 expressive TTS 的真痛点（用户经常想"前半句平静、后半句激动"）。论文有完整 ablation（章节 "Analysis: Style Vectors in Embedding Space"、"Quantitative Analysis of Early-Token Attention Bias"），方法论扎实。批判性看：没看到与 [[EmotionThinker]]、[[NVSpeech]] 这种最新表达性 TTS 的对比；abstract 没给具体的 SPS 数字提升幅度。属于"想法新、方法扎实但 SOTA 比较待验证"的范畴。🔥
- **🧪 锐评依据**:
  - `Claim: prompt-based TTS 的全句单一风格是真痛点` | `Evidence: abstract "they often provide limited fine-grained control and apply a single global style across an utterance"` | `Confidence: 高`
  - `Claim: early-token attention bias 是新发现` | `Evidence: Appendix C "Quantitative Analysis of Early-Token Attention Bias"，独立成节` | `Confidence: 中`
  - `Claim: 没跟最新表达性 TTS 直接对比` | `Evidence: method_names 里没有 EmotionThinker / NVSpeech / NaturalSpeech3` | `Confidence: 中`
- **关联笔记**: 跟 [[EmotionThinker]]（情感推理）、[[NVSpeech]]（情感数据）、[[CosyVoice2]] / [[CosyVoice3]]（prompt-based 主流）形成对照。如果 within-utterance control 真能用 KV cache 操作实现，是个轻量级方案。

### 4. Bridging the Stability-Expressivity Gap: Synthetic Data Scaling and Preference Alignment for Low-Resource Spoken Language Models
- **作者**: Yizhong Geng, Yanliang Li, Jinghan Yang, Tianhan Jiang, Boxun An, Ya Li, Xiaoyu Shen
- **机构**: 未在 enriched data 中明确列出

- **来源**: 📄 arXiv 关键词检索

- **核心方法**: 针对 Spoken Language Model 在低资源语言上"要么稳定但单调（高 WER 低 expressivity）要么 expressive 但容易崩"的两难。两个方法：① **DGSA (Disentanglement-Guided Self-Alignment)** — 用 [[DPO]] + disentanglement loss 分离 stability 和 expressivity；② **TDSC (Temperature-Driven Self-Critique)** — 通过温度变化产生 critique 信号做 self-alignment。配合 synthetic data 扩展（用 [[ElevenLabs]] / [[TTS]] 生成 paired data），用 [[Flow-Matching]] 训练，[[MMS]] 做评测。
